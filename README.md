 # Secure-Password-Generator-Java

Secure Java password generator using SecureRandom with customizable character sets and strength evaluation. 🔐 Built a Secure Password Generator using Java

I recently built a password generator that allows users to create strong, random passwords based on selected criteria.

💡 Features: ✔ Custom password length ✔ Choice of uppercase, lowercase, digits, special characters ✔ SecureRandom for cryptographic strength ✔ Password strength evaluation (Weak / Medium / Strong) ✔ Shuffling for improved randomness

🧠 What I learned:

SecureRandom vs Random in Java
StringBuilder optimization
Basic security principles in password generation
Input handling and logic building
This project helped me understand how real-world password generation works in security systems.
